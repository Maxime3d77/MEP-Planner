# Redmine

Configure the Redmine URL, API key, tag field, environment field and start/end time custom fields. MEP Planner reads issues carrying the configured MEP tag. Use a dedicated API account with only the permissions required to read projects and issues.


## Dynamic categories

MEP Planner can track any number of Redmine tag values. Open **Settings → Redmine**, then use **Tracked Redmine tags** to add or edit categories. Each category controls its own dashboard section, sidebar history entry, calendar visibility, notifications and report statistics. The old single tag value field is retained internally only for backward compatibility.
